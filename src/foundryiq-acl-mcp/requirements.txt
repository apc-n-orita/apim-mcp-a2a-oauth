# 1.8.6 以降を要求する。1.8.5 以前は既定サンプラーが
# ApplicationInsightsSampler(sampling_ratio=1.0) で全トレースを保持するのに対し、
# 1.8.6 以降は RateLimitedSampler(5.0) が既定になる。
# telemetry.py の enable_trace_based_sampling_for_logs=False はこの既定を前提にしている。
#
# 実際に解決されるのは 1.8.6。下の opentelemetry-sdk のピンが上限として効くため:
#   1.8.6       -> opentelemetry-sdk==1.39
#   1.8.7/1.8.8 -> opentelemetry-sdk==1.40
#   1.8.9       -> opentelemetry-sdk~=1.43.0
# sdk のピンを動かすときは、azure-monitor-opentelemetry も併せて確認すること。
azure-monitor-opentelemetry>=1.8.6
opentelemetry-api==1.39.0
opentelemetry-sdk==1.39.0
